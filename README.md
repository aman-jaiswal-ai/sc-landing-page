# 🎓 SnapClass AI

AI-powered smart attendance system using Face Recognition and Voice Biometrics for secure and automated classroom attendance management.

---

# 🚀 Features

- Face Recognition Attendance
- Voice-Based Attendance
- AI Student Authentication
- Teacher Dashboard
- Student Portal
- Attendance Analytics
- Subject Enrollment System
- Reset Face & Voice Biometrics

---

# 🛠️ Tech Stack

- Python
- Streamlit
- Supabase
- dlib
- Scikit-learn
- Librosa
- HTML/CSS/JavaScript
- Vercel
- Streamlit Cloud

---

# ▶️ Run Project

Install dependencies:

```bash
pip install -r requirements.txt
```

Run application:

```bash
streamlit run app.py
```

---

# 🌐 Deployment

- Frontend → Vercel
- AI App → Streamlit Cloud
